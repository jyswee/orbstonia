## 🌌 What is ORBSTONIA?

Six Orb Stones are scattered across a glowing vector arena. Hunt them, claim them,
and complete the set before your rivals do — the first to hold all six takes the
throne. **Pure neon. Pure speed. Pure skill.**

- ⚡ **Real-time multiplayer** — see every rival move as it happens
- 🔷 **Six typed Orb Stones** — each a distinct wireframe shape to race for
- 🕹️ **80s vector look, modern feel** — Tron-grade neon, bloom, particle trails
- 📱 **Play anywhere** — desktop, mobile twin-stick, or instant in-browser
- 🎨 **Fair by design** — cosmetics only, never pay-to-win

## 🎮 How to Play

- **Desktop** — WASD / arrows to move, mouse to look, race to each stone and claim it first.
- **Mobile** — twin-stick touch controls: left pad moves, right pad aims.
- **Goal** — be the first player to hold all six Orb Stones. Block rivals, cut routes, own the grid.
